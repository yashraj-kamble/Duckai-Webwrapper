# duckai-sidebar

A native Wayland sidebar panel for [Duck.ai](https://duck.ai), built in C with **WebKitGTK** and **GTK Layer Shell**, engineered specifically for **Hyprland** and Wayland compositors.

Unlike conventional Electron or Pake wrapper windows forced into floating rules or special workspaces, `duckai-sidebar` acts as a true desktop layer panel:
- It claims a **dynamic exclusive zone** on your screen edge: tiled windows smoothly adjust their layout to make room when the sidebar opens, and reclaim full screen width when it closes.
- Pressing **`SUPER+D`** toggles the sidebar instantly. The WebKit engine and your Duck.ai chat session stay alive in the background without reloading or losing state.
- If the application is not running when the shortcut is pressed, it launches the daemon and displays the panel automatically.
- Single-instance IPC guarantees that repeated key presses never spawn duplicate panels.

## Features

- **Genuine Wayland Layer-Shell Panel**: Uses `zwlr_layer_shell_v1` (via `gtk-layer-shell`) to dock flush against the screen edge.
- **Exclusive Zone Management**: Automatically reserves space (default 420 px) so active tiled windows do not overlap or get covered. When hidden, the window is unmapped and the exclusive zone is immediately released.
- **Instant Toggle & Session Persistence**: Toggling hides and shows the surface without quitting or refreshing. Your ongoing AI chat, selected model, and DuckDuckGo login session are preserved across toggles and reboots via persistent SQLite cookie and local storage.
- **Single-Instance IPC**: Ultra-fast local Unix domain socket IPC (`$XDG_RUNTIME_DIR/duckai-sidebar.sock`). Commands like `duckai-sidebar --toggle`, `--show`, `--hide`, `--reload`, and `--status` communicate with the running daemon in sub-milliseconds.
- **Active Monitor Tracking**: When toggling with multiple displays, `duckai-sidebar` automatically queries Hyprland to anchor to whichever monitor is currently focused.
- **Configurable Edge & Width**: Dock to the `right` (default) or `left` edge; configure width (default `420` px) statically via `config.ini` or on the fly via CLI flags.
- **Native Input & Smart Navigation**:
  - Full keyboard interactivity with `on-demand` focus: click into the chat box to type, click outside to focus your editor or terminal without modal lockups.
  - Links to external sites generated by the AI automatically open in your default browser instead of navigating away from your chat.
  - Duck.ai and DuckDuckGo authentication popups share the same session context for login.
- **Restrained, Themeable Styling**: Starts without titlebar or window decorations. Themed with native GTK CSS (`duckai-sidebar.css`), honoring your desktop theme colors and dark mode settings.

## System Requirements (Arch Linux)

Verify and install the required official Arch Linux packages:

```bash
sudo pacman -S --needed \
    base-devel \
    gtk3 \
    gtk-layer-shell \
    webkit2gtk-4.1 \
    glib2 \
    meson \
    ninja \
    pkgconf \
    gcc
```

Package roles:
- `gtk-layer-shell` — Library providing Wayland `zwlr_layer_shell_v1` integration for GTK.
- `webkit2gtk-4.1` — Modern WebKit2 engine (libsoup3 ABI) for embedding web content.
- `gtk3`, `glib2` — Core toolkit and event loop runtime.
- `meson`, `ninja`, `pkgconf`, `gcc` — Modern build system.

## Installation

### Option 1: Arch Linux PKGBUILD (Recommended)

Build and install a native `.pkg.tar.zst` using `makepkg`:

```bash
git clone https://github.com/yashraj-kamble/duckai-sidebar.git
cd duckai-sidebar

# Build and install package with pacman
makepkg -si
```

Or run the included helper:
```bash
bash scripts/build-arch.sh
bash scripts/install-arch.sh
```

### Option 2: Build with Meson / Ninja

```bash
git clone https://github.com/yashraj-kamble/duckai-sidebar.git
cd duckai-sidebar

# Configure and compile
meson setup build --prefix=/usr
ninja -C build

# Install to system
sudo ninja -C build install
```

### Option 3: Traditional Makefile

```bash
make
sudo make install
```

## Hyprland Configuration

Add the toggle binding to your `~/.config/hypr/hyprland.conf`:

```ini
# Toggle Duck.ai sidebar on SUPER+D
bind = $mainMod, D, exec, duckai-sidebar --toggle
```

### Optional: Preload on Login (Zero-Latency First Open)

To make your very first `SUPER+D` press instant, you can preload `duckai-sidebar` hidden in the background on startup:

```ini
# Add to ~/.config/hypr/hyprland.conf:
exec-once = duckai-sidebar --hidden
```

### Optional: Blur & Effects

Because `duckai-sidebar` registers under the layer-shell namespace `duckai-sidebar`, you can apply compositor layer rules:

```ini
# Smooth slide animation
layerrule = animation slide left, duckai-sidebar

# Optional blur effect (if using semi-transparent CSS themes)
# layerrule = blur, duckai-sidebar
# layerrule = ignorezero, duckai-sidebar
```

Then reload Hyprland:
```bash
hyprctl reload
```

## Command Line Interface & IPC

`duckai-sidebar` acts as both the background daemon and the CLI control client:

```bash
duckai-sidebar [OPTIONS]
```

### Actions

| Flag | Description |
|------|-------------|
| `-t`, `--toggle` | Toggle panel visibility (starts the daemon if not already running) |
| `-s`, `--show` | Show the sidebar panel |
| `--hide` | Hide the sidebar panel and release exclusive zone |
| `-r`, `--reload` | Reload the Duck.ai webview |
| `--reload-bypass` | Reload Duck.ai bypassing HTTP cache |
| `-q`, `--quit` | Terminate the running sidebar daemon |
| `--status` | Query running state, visibility, and current monitor |

### Configuration Overrides

| Flag | Description |
|------|-------------|
| `-w`, `--width <px>` | Set panel width in pixels (e.g. `--width 480`) |
| `-e`, `--edge <left\|right>` | Anchor to `left` or `right` screen edge |
| `-m`, `--monitor <name>` | Specify target monitor (`active` or connector like `eDP-1`) |
| `-H`, `--hidden` | Start daemon in hidden state (for `exec-once`) |
| `--header` | Show minimal top navigation strip |
| `--no-header` | Hide navigation header (pure webview, default) |
| `-u`, `--url <url>` | Custom URL (default: `https://duck.ai`) |
| `-c`, `--config <file>` | Path to custom INI configuration file |
| `--dump-config` | Print parsed configuration and exit |
| `-v`, `--version` | Display version information |
| `-h`, `--help` | Display help reference |

### Examples

```bash
# Toggle the sidebar (launches if not running)
duckai-sidebar --toggle

# Change width to 500px on the fly while running
duckai-sidebar --width 500

# Move sidebar to the right edge dynamically
duckai-sidebar --edge right

# Check running status
duckai-sidebar --status
# Output: STATUS visible=1 width=420 edge=left monitor=eDP-1
```

## Configuration File

You can customize `duckai-sidebar` permanently by placing a configuration file at:
`~/.config/duckai-sidebar/config.ini`

```ini
[general]
# URL to embed
url = https://duck.ai

# Width in pixels (default: 420)
width = 420

# Screen edge: "left" or "right" (default: right)
edge = right

# Layer: "top", "overlay", "bottom", or "background" (default: top)
layer = top

# Target monitor: "active" (tracks active workspace) or specific connector (eDP-1)
monitor = active

# Enable exclusive zone so tiled windows yield space
exclusive_zone = true

# Keyboard interactivity: "on-demand" (recommended), "exclusive", or "none"
keyboard_mode = on-demand

# Minimal header bar with reload and new-chat buttons (default: false)
show_header = false

# Pressing Escape hides the sidebar
close_on_escape = true

[appearance]
# Border width in pixels (default: 2)
border_width = 2

# Border color (CSS color, hex e.g. #33ccff, or rgba)
# Leave blank to use desktop accent color (@theme_selected_bg_color)
border_color = 

# Border placement: "inner" (facing tiled windows) or "all" (all sides)
border_mode = inner

[margins]
top = 0
bottom = 0
left = 0
right = 0

[webview]
enable_smooth_scrolling = true
enable_webgl = true
enable_clipboard = true
user_agent = 
```

## Styling & Theming

`duckai-sidebar` uses GTK CSS styling that automatically respects your system's GTK theme (Adwaita, Catppuccin, Gruvbox, Arc, etc.) via standard `@theme_bg_color` and `@theme_fg_color` tokens.

To customize the styling, create `~/.config/duckai-sidebar/style.css`:

```css
/* Custom background or borders */
window.duckai-sidebar-window {
    background-color: #1e1e2e;
    color: #cdd6f4;
}

/* 1px separator line next to tiled windows */
.duckai-sidebar-left {
    border-right: 1px solid rgba(205, 214, 244, 0.15);
}

.duckai-sidebar-right {
    border-left: 1px solid rgba(205, 214, 244, 0.15);
}
```

## Architecture & Wayland Considerations

### GTK Layer Shell vs Floating Window Hacks

| Approach | Pake / Floating Window | `duckai-sidebar` (GTK Layer Shell) |
|---|---|---|
| **Compositor Protocol** | `xdg_shell` (regular app window) | `zwlr_layer_shell_v1` (native desktop surface) |
| **Window Tiling** | Requires floating rules, covers tiled windows | Claims **exclusive zone**; tiled windows automatically shrink and reflow |
| **Hiding / Showing** | Workspace jumping, special scratchpads | Native surface unmapping; zero compositor artifacts |
| **Resource Overhead** | Heavy Rust/Tauri/Cargo stack (~150MB+ build tree) | Native C binary (< 70KB executable, 0 extra runtimes) |
| **Build Time** | 10–20 minutes (Cargo dependencies) | **< 3 seconds** with Meson + GCC |

### Documented Limitations & Technical Notes

1. **Wayland Keyboard Interactivity (`on-demand`)**:
   Under the Wayland Layer Shell protocol, panels use `GTK_LAYER_SHELL_KEYBOARD_MODE_ON_DEMAND`. When you open the sidebar, click inside the chat field to focus and type. You can click back into any tiled window at any time without window focus trapping.
2. **Wayland Status Bars**:
   If you run Waybar or other status bars that also reserve top/bottom space, `duckai-sidebar` automatically stretches between them without overlapping, as Hyprland coordinates exclusive zones across all active layer surfaces.
3. **Session Persistence**:
   Cookies and web storage are stored in `~/.local/share/duckai-sidebar/` using WebKit's SQLite backend. If you ever want to reset your Duck.ai chat session or log out completely, simply delete that directory or clear cookies from the settings.
